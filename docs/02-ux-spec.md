# 页面与交互规格

## 1. 全局布局

MVP 以 Desktop Web 为主。布局采用左侧导航 + 顶部标题栏 + 主内容区。

左侧导航：

- 首页看板
- 月度快照
- 机构与账户
- 债权债务
- 设置

全局要求：

- 页面风格偏财务后台，信息密度适中，避免营销式大卡片。
- 金额字段统一右对齐，数字使用千分位。
- 所有 CNY 折算金额显示“¥”或“CNY”，原币金额显示币种代码。
- 外币折算金额旁可显示使用汇率和 stale 标记。
- 删除、恢复、覆盖等破坏性操作必须使用确认对话框。

## 2. 首页看板

### 2.1 首屏结构

顶部 KPI 区：

- 当前总资产
- 当前总负债
- 当前净资产
- 较上月变化
- 外币正资产占比

KPI 下方图表区：

- 净资产月度趋势
- 资产组成比例
- 流动性分布
- 风险分布
- 币种占比
- Top 5 机构
- 项目金额变化榜

### 2.2 指标规则

总资产：正资产合计，包含银行、现金、证券、债权。

总负债：债务未偿本金合计。

净资产：总资产减总负债。

Top 5 机构：按正资产金额排序，不按项目数。债务不拉低机构排名。

币种占比：只看正资产折算金额。

金额变化榜：展示本月金额减上月金额，名称使用“金额变化”，不使用“收益”。

## 3. 月度快照页

### 3.1 入口

页面顶部包含：

- 快照日期选择器
- 复制上月项目清单按钮
- 导入月度快照按钮
- 保存按钮
- 缺失项提示

### 3.2 表格列

表格建议使用 MUI X Data Grid。

列：

- 机构
- 账户
- 项目
- 资产类型
- 币种
- 原币金额
- CNY 折算金额
- 使用汇率
- 汇率状态
- 流动性
- 风险
- 较上月变化
- 备注

### 3.3 保存逻辑

保存时逐行校验：

- 原币金额必须是数字
- 项目币种必须在用户启用币种内
- 项目必须处于启用状态
- 同一项目同一快照日期只能有一条快照

若较上月变化超过 20000 CNY 或 20%，显示建议填写备注的提示，但允许用户继续保存。

历史月份始终可编辑，但每次保存必须写操作日志。

## 4. 机构与账户页

### 4.1 页面结构

左侧或上方为机构列表，右侧展示选中机构下的账户和项目。机构列表顶部固定提供“待关联账户”分组，集中显示尚未选择机构的账户。

机构卡片或表格字段：

- 名称
- 类型
- 正资产金额
- 项目数
- 启用状态

新增或编辑账户时，“所属机构”使用选择框，并提供“暂不关联（稍后设置）”。用户可以先建立账户，再通过编辑账户完成关联或解除关联；关联后账户从“待关联账户”移动到对应机构。

账户区域字段：

- 账户名称
- 类型
- 脱敏标识
- 当前资产金额
- 启用状态

项目区域字段：

- 项目名称
- 资产类型
- 币种
- 默认流动性
- 默认风险
- 当前金额
- 启用状态
- 备注

### 4.2 项目维护

项目在机构与账户页内维护。用户进入某账户后添加项目。

现金钱包在现金机构下维护，用户可创建多个现金钱包账户。

停用项目不出现在新月份必填列表中，但历史数据保留可查。

未关联账户下的项目不进入月度快照。停用机构或账户后，其下所有项目在月度快照中隐藏，包括已有历史月份；快照记录不删除，完成关联或重新启用上级后恢复显示。

机构、账户、项目列表均提供删除入口，并在执行前显示确认对话框。机构存在账户、账户存在项目或项目存在快照记录时，服务端阻止删除；对话框保留并展示原因。删除成功后刷新三级列表和快照数据。

### 4.3 历史快照

机构、账户、项目每行提供“查看历史”入口，并进入同一个历史快照页面。页面结构为：

- 标题、当前层级和“当前关联关系实时汇总”说明
- 近 12 个月、近 24 个月、全部和自定义起止日期
- 最新金额、较上一期变化、历史最高、历史最低
- CNY 折算金额趋势图
- 机构按账户、账户按项目展示最新一期构成；项目层级不重复显示构成
- 原币金额、币种、汇率、CNY 折算、变化、汇率状态和备注明细表
- CSV 导出

账户重新关联后，全部历史按新机构重新汇总；不保留或展示旧机构归属。停用机构、账户和项目仍可查看历史。

## 5. 债权债务页

页面分为两个标签：

- 债权
- 债务

列表字段：

- 交易对手
- 币种
- 当前未偿本金
- CNY 折算金额
- 状态
- 最近事件日期
- 备注

详情页包含事件时间线：

- 新增借款
- 还款
- 调整
- 结清

事件保存后立即刷新未偿本金。负数余额不允许保存，除非事件类型为调整且用户确认。

## 6. 设置页

设置页包含以下分区：

币种设置：

- 默认候选币种
- 用户启用币种
- 启用数量上限

汇率：

- 最近同步时间
- 同步状态
- 每个币种最新汇率
- stale 汇率说明

导入导出：

- 下载机构/账户/项目模板
- 下载月度快照模板
- 下载债权债务事件模板
- 上传模板并校验
- 导出完整备份
- 恢复完整备份

账户安全：

- 修改显示名称，保存后立即刷新侧栏资料
- 修改密码，需要验证当前密码并确认新密码
- 查看登录日志

## 7. 空态和错误态

首次登录后如果没有数据，首页显示引导：

1. 配置启用币种
2. 创建机构与账户
3. 添加项目
4. 录入第一个月度快照

汇率缺失时：

- 如果存在历史可用汇率，使用最近可用汇率并显示 stale
- 如果完全没有可用汇率，阻止保存该外币快照并提示先同步或手动导入汇率

导入失败时：

- 显示错误行号
- 显示字段名
- 显示错误原因
- 不写入任何部分数据
