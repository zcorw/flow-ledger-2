# 开发任务拆分

## 1. 里程碑 0：工程骨架

目标：搭起可运行、可部署、可迁移的基础工程。

任务：

1. 创建 monorepo 结构：`frontend`、`backend`、`docs`、`deploy`。
2. 前端使用 React + MUI + TanStack Query + React Hook Form + Zod。
3. 后端使用 FastAPI + SQLAlchemy + Alembic。
4. 配置 Postgres。
5. 编写 Dockerfile 和 docker-compose。
6. 增加健康检查接口。
7. 增加基础 CI：lint、typecheck、test。

验收：

- `docker compose up` 后可访问前端、API 和数据库。
- `/api/v1/system/health` 返回正常。
- Alembic 可以执行首个迁移。

## 2. 里程碑 1：初始化和认证

任务：

1. 实现首次初始化页面。
2. 实现 `BOOTSTRAP_TOKEN` 校验。
3. 创建管理员账号。
4. 初始化默认币种和默认现金机构。
5. 实现登录、退出、当前用户、修改密码。
6. 实现认证中间件。

验收：

- 无用户时进入初始化页面。
- 管理员创建后初始化入口失效。
- 未登录无法访问业务页面。

## 3. 里程碑 2：币种和汇率

任务：

1. 建立 currencies、user_currencies、fx_rates、fx_sync_runs 表。
2. 实现币种启用设置，限制最多 5 个。
3. 实现汇率同步服务。
4. 实现 APScheduler 独立容器，每天 08:00 同步。
5. 实现汇率查询和 stale fallback。
6. 设置页展示最近汇率和同步状态。

验收：

- 用户可启用 CNY、USD、JPY、HKD、EUR 中最多 5 个。
- 同步任务写入历史汇率。
- 快照日期无当日汇率时能使用之前最近汇率并标记 stale。

## 4. 里程碑 3：机构、账户、项目

任务：

1. 建立 institutions、accounts、projects 表。
2. 实现机构 CRUD。
3. 实现账户 CRUD，并支持先创建账户、后关联或解除关联机构。
4. 实现项目 CRUD 和停用。
5. 实现现金钱包模型。
6. 在机构与账户页内维护项目。

验收：

- 用户可创建招商银行、盈透证券、现金机构。
- 用户可创建储蓄卡、理财账户、证券账户、现金钱包。
- 未关联账户显示在独立分组中，关联机构后自动归入对应机构。
- 用户可在账户下创建活期余额、季季宝、美股组合等项目。
- 停用项目不出现在新月份缺失提醒中。

## 5. 里程碑 4：月度快照

任务：

1. 建立 monthly_snapshots 表。
2. 实现按日期加载快照。
3. 实现表格式批量录入。
4. 实现复制上月项目清单。
5. 实现缺失提醒。
6. 实现金额变化计算。
7. 实现手动备注。
8. 实现保存时汇率折算。
9. 实现操作日志。

验收：

- 用户选择快照日期后看到所有启用项目。
- 可批量保存原币金额。
- 外币项目自动折算 CNY。
- 较上月变化超过 20000 CNY 或 20% 时提示备注。
- 历史月份可编辑并写日志。

## 6. 里程碑 5：债权债务

任务：

1. 建立 debt_items、debt_events 表。
2. 实现债权债务列表。
3. 实现债权债务创建和状态维护。
4. 实现事件时间线。
5. 实现未偿本金计算服务。
6. 将债权债务汇总接入首页指标。

验收：

- 可创建“朋友 A 借出款”。
- 可添加新增借款、还款、调整、结清事件。
- 系统能计算某日期未偿本金。
- 债权计入总资产，债务计入总负债。

## 7. 里程碑 6：首页看板

任务：

1. 实现 dashboard summary API。
2. 实现 dashboard charts API。
3. 实现顶部 KPI。
4. 实现净资产趋势图。
5. 实现资产组成、流动性、风险、币种占比图。
6. 实现 Top 5 机构。
7. 实现金额变化榜，避免使用“收益”命名。

验收：

- 首页首屏能看清总资产、总负债、净资产和较上月变化。
- 所有图表均可基于月度快照和债权债务事件正确生成。
- Top 5 按正资产金额排序。

## 8. 里程碑 7：导入导出和恢复

任务：

1. 设计三个模板：机构/账户/项目、月度快照、债权债务事件。
2. 实现模板下载。
3. 实现上传校验。
4. 实现冲突检测，冲突整批拒绝。
5. 实现完整备份导出。
6. 实现恢复前密码重认证。
7. 恢复前自动备份当前数据。
8. 实现全量替换恢复。

验收：

- 导入错误显示行号和字段。
- 冲突不会写入部分数据。
- 恢复前必须输入当前密码。
- 恢复前会生成当前数据备份。

## 9. 里程碑 8：部署和运维

任务：

1. 完成生产 docker-compose。
2. 配置 GitHub Actions 部署到 VPS。
3. 配置数据库迁移命令。
4. 配置定时数据库备份。
5. 配置日志目录。
6. 配置健康检查。

验收：

- 推送 main 后可自动部署。
- 部署后迁移自动执行或有明确手动步骤。
- 数据库每天自动备份。
- 可以查看 API 日志、scheduler 日志和汇率同步日志。
