# 可用性与性能质量预算

## 目标规模

基准数据为 100 个资产项目、连续 60 个月、共 6,000 条月度快照。自动测试会验证：

- 月度快照接口返回 100 行时 SQL 查询数不超过 8 次，响应时间小于 2 秒。
- 同一请求批量更新 100 个项目并写入审计记录，响应时间小于 2 秒。
- 首页图表返回最近 12 个月趋势，响应时间小于 3 秒。
- 关键组合索引随 Alembic `0008_performance_indexes` 迁移创建。

运行方式：

```sh
cd backend
python -m pytest tests/test_performance.py --durations=3
```

当前开发机完整基准用例为 0.55 秒。时间阈值为共享 CI 留有余量；生产 VPS 应在导入真实数据后用相同规模复测。

## 前端包体积预算

所有页面使用动态路由块，ECharts 仅注册实际使用的折线、柱状、饼图和 SVG 模块。构建后的 gzip 预算为：

| 资源 | 预算 | 当前基线 |
| --- | ---: | ---: |
| 初始应用 | 100 KiB | 76.51 KiB |
| 首页看板路由 | 220 KiB | 189.92 KiB |
| 月度快照路由 | 160 KiB | 139.58 KiB |

运行 `pnpm build && pnpm bundle:check`。CI 会在任一预算超限时失败。

## 可访问性门禁

`pnpm e2e` 使用 axe 扫描初始化页、空看板、主数据页、月度快照表格和移动端看板，覆盖 WCAG 2 A/AA；严重或关键问题会使测试失败并附加完整 JSON 报告。

同一流程还验证：

- 首次 Tab 可聚焦“跳到主要内容”，Enter 后焦点进入主内容。
- 所有操作具有可见的 `:focus-visible` 轮廓。
- 390 × 844 视口下可打开移动导航，并可用 Escape 关闭。
- `prefers-reduced-motion: reduce` 下 CSS 过渡和 ECharts 动画关闭。
- Data Grid 具有可访问名称，并保留原生键盘单元格编辑方式。

手动发布检查应再覆盖 200% 页面缩放、仅键盘完成一次快照录入，以及浅色屏幕下的警告/错误颜色辨识。
