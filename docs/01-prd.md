# 产品需求文档

## 1. 背景

用户需要管理银行、证券、现金、债权和债务等资金资产，并快速了解每月净资产变化、资产组成比例、币种敞口、流动性分布和风险分布。

现阶段重点不是自动同步真实账户，也不是完整记账，而是把分散在银行、券商和个人借贷关系中的资产整理成结构化月度快照。

## 2. 产品目标

MVP 需要满足：

1. 用户可以维护不同机构、账户和项目。
2. 用户可以按月快速录入每个项目的原币金额。
3. 系统自动按历史汇率折算为 CNY。
4. 用户可以查看当前总资产、总负债、净资产和较上月变化。
5. 用户可以查看资产组成、流动性、风险、币种和 Top 5 机构分布。
6. 用户可以独立维护债权债务事件，并按未偿本金进入净资产计算。
7. 用户可以导入基础数据和月度数据，也可以备份和恢复全量数据。

## 3. 用户角色

MVP 只有一个实际角色：私有管理员用户。

管理员用户可以：

- 登录系统
- 初始化和修改自己的显示名称、密码
- 配置币种
- 创建机构、账户、项目
- 录入和修改月度快照
- 维护债权债务事件
- 导入、导出、备份、恢复数据
- 查看汇率同步状态和操作日志

## 4. 核心实体

机构：银行、券商、现金、个人或其他资金来源。

账户：机构下的容器，例如储蓄卡、理财账户、证券账户、现金钱包。

项目：每月录入金额的最小资产单位，例如活期余额、季季宝、美股组合。

月度快照：某个日期某个项目的原币金额、折算金额、风险、流动性和备注。

债权债务账本：独立维护应收和应付项目，通过事件计算未偿本金。

汇率：币种对 CNY 的历史汇率。

## 5. 功能范围

### 5.1 认证和初始化

首次部署后，如果系统没有管理员用户，访问应用进入初始化页面。初始化需要输入环境变量中配置的 `BOOTSTRAP_TOKEN`，再设置管理员邮箱、用户名和密码。

管理员创建完成后，初始化入口失效。后续只能通过登录页进入系统。

### 5.2 首页看板

首页使用月份选择器。项目资产只统计所选自然月内的快照，同一项目当月存在多条时取最后一条；当月没有快照的项目不计入且不沿用以前月份。债权债务按所选月月末未偿余额统计。

首页展示：

- 当月总资产
- 当月总负债
- 当月净资产
- 较上月净资产变化
- 外币正资产占比
- 净资产月度趋势
- 资产组成比例
- 流动性分布
- 风险分布
- 币种占比
- Top 5 机构
- 金额变化，不命名为收益

### 5.3 机构与账户

用户可以维护机构、账户和账户下项目。

机构字段：

- 名称
- 机构类型
- 显示颜色
- 启用状态

账户字段：

- 所属机构（可选，可在创建账户后再关联或解除关联）
- 名称
- 账户类型
- 脱敏标识
- 显示颜色
- 启用状态

未关联机构的账户集中显示在“待关联账户”中。账户可以先创建项目，但只有关联到启用机构后，其项目才进入月度快照。

层级资料支持受保护删除：机构下没有账户时可删除机构，账户下没有项目时可删除账户，项目没有任何月度快照记录时可删除项目。存在子记录或历史快照时必须阻止删除并给出明确提示；已有快照的项目可改为停用。

项目字段：

- 所属账户
- 项目名称
- 资产类型
- 币种
- 默认流动性等级
- 默认风险等级
- 启用状态
- 备注

### 5.4 现金钱包

现金作为显式现金钱包维护。系统可创建一个内置机构“现金”，用户在其下创建现金钱包账户，例如人民币现金、日元现金、备用金。

现金钱包仍通过项目和月度快照进入首页统计。

### 5.5 月度快照

用户选择快照日期后进入表格式录入页面。页面列出已关联机构且所属机构、账户和项目均处于启用状态的项目，用户填写原币金额和备注。未关联账户、停用机构或停用账户下的全部项目从快照页面隐藏，但历史数据仍保留；关联或重新启用上级后恢复显示。

保存时系统：

- 校验项目币种是否启用
- 查找快照日期对应汇率
- 若当日汇率缺失，取该日期之前最近可用汇率并标记 stale
- 计算 CNY 折算金额
- 保存操作日志

### 5.6 历史快照

机构、账户和项目均可进入统一历史快照页面。页面提供最新金额、较上一期变化、筛选范围内最高和最低金额、金额趋势、最新一期下级构成、逐条快照明细以及 CSV 导出。

历史始终按当前层级关系实时汇总，不在月度快照中独立保存机构或账户归属。用户重新关联账户代表修正原有关联，因此该账户下全部项目的历史数据同步转移到新机构，旧机构不再包含这些历史。停用状态仅影响月度录入，不影响历史查询。

### 5.7 债权债务

债权债务使用独立账本。

债权债务项目字段：

- 类型：债权或债务
- 交易对手
- 币种
- 状态
- 备注

事件字段：

- 事件类型：新增、还款、调整、结清
- 发生日期
- 金额
- 交易对手
- 备注

系统按事件计算某日期的未偿本金。债权计入正资产，债务计入总负债。

### 5.8 设置

设置页包含：

- 币种列表和启用币种
- 用户币种上限，默认 5
- 汇率同步状态和历史
- 集中导入导出：机构/账户/项目、历史汇率、月度快照和债权债务事件均在设置页操作
- 历史汇率支持 CSV 模板下载、全量预校验和批量导入；同币种、日期、来源再次导入时更新原记录
- 主数据导出包含当前上下级关联、停用数据和待关联账户
- 月度快照按日期范围导出；债权债务事件按类型和日期范围导出
- 备份恢复
- 修改显示名称
- 修改密码
- 操作日志

## 6. 验收标准

MVP 通过以下验收：

1. 用户可以完成首次管理员初始化并登录。
2. 用户可以创建银行、券商和现金钱包，并为它们添加项目。
3. 用户可以启用最多 5 个币种，默认包含 CNY、USD、JPY、HKD、EUR。
4. 系统每天 08:00 执行汇率同步任务，并记录同步结果。
5. 用户可以选择快照日期，批量录入项目金额并保存。
6. 首页可以展示当前总资产、总负债、净资产和较上月变化。
7. 首页图表可以按资产类型、币种、流动性、风险和机构展示分布。
8. 债权债务可以通过事件增减未偿本金，并进入净资产计算。
9. 四类 CSV 导入均先完整校验；业务数据冲突会被拒绝并给出错误行说明，历史汇率允许按唯一键更新。
10. 恢复备份前必须重新输入密码，并自动备份当前数据。
