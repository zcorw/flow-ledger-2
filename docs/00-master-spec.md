# 资金资产管理 Web 应用开发总文档

## 1. 产品定位

本应用用于个人资金资产管理，帮助用户通过 Desktop Web 页面快速了解自身资产每个月的变化、不同资产部分组成比例、币种敞口、流动性分布和风险分布。

首版不是记账软件，不追踪每笔消费流水，不对接银行或券商 API，不计算真实投资收益率。MVP 以手动月度快照为核心，用户按项目录入每月资产余额，系统用历史汇率折算到基础货币 CNY，并生成看板分析。

## 2. 已确认范围

目标用户：个人私有使用。

部署方式：单机 Docker Compose 部署到 VPS。

前端：React + MUI，Desktop 优先。

后端：FastAPI + SQLAlchemy + Alembic。

数据库：Postgres。

定时任务：APScheduler 独立服务。

图表：Apache ECharts。

表格录入：MUI X Data Grid。

表单校验：React Hook Form + Zod。

请求缓存：TanStack Query。

认证：账号密码登录。首次初始化管理员需要明确设置流程。

## 3. 核心业务决策

基础货币为 CNY。用户可启用最多 5 个币种，默认候选币种为 CNY、USD、JPY、HKD、EUR。币种列表和用户币种上限必须可配置。

汇率每天 08:00 自动同步，只同步用户启用币种，并保留历史汇率。月度快照使用用户选择的快照日期对应汇率。若当天汇率缺失，使用该日期之前最近一条可用汇率，并标记为 stale。

数据层级为：机构 -> 账户 -> 项目 -> 月度快照。

项目指金融产品或持仓组合，例如活期余额、季季宝、美股组合。项目按月记录原币金额、折算金额、流动性等级、风险等级和备注。

现金使用显式现金钱包。实现上可使用系统内置“现金”机构，用户在其下创建现金钱包账户和现金项目。

债权债务使用独立账本，不作为普通项目维护。债权债务通过事件记录新增借款、还款、调整、结清等变化，按未偿本金进入净资产计算。

总资产只统计正资产。债务不计入总资产，只进入总负债，并从净资产中扣减。推断决策：债权/应收作为正资产计入总资产，因为它属于用户选择的资产范围且影响净资产。

Top 5 机构按正资产金额排序，不按项目数。

币种占比只看正资产。

停用项目历史仍可见，当前月份不再要求录入。

MVP 不做真实投资收益分析。首页可以展示“金额变化”，但不得命名为“收益”或“投资收益率”。

## 4. 主导航

MVP 主导航包含：

- 首页看板
- 月度快照
- 机构与账户
- 债权债务
- 设置

导入导出不作为一级导航，放在设置页，并在月度快照、机构与账户、债权债务页面提供入口。

项目管理不作为一级导航。项目在“机构与账户”页内维护，打开某个账户后管理该账户下项目。

## 5. 首页首屏

布局采用顶部 KPI + 下方图表。

顶部 KPI：

- 当前总资产：正资产合计，含银行存款、现金、证券、债权
- 当前总负债：债务未偿本金合计
- 当前净资产：总资产减总负债
- 较上月变化：当前净资产减上月净资产
- 外币资产占比：正资产中非 CNY 折算金额占比

下方图表：

- 净资产月度趋势
- 资产组成比例
- 流动性分布
- 风险分布
- 币种占比
- Top 5 机构
- 金额变化列表或图表，不命名为收益

## 6. 月度快照

月度快照主流程为表格式批量录入。

用户选择快照日期，系统显示所有启用项目。用户逐行填写原币金额，系统根据项目币种和历史汇率计算 CNY 折算金额。

辅助能力：

- 复制上月项目清单
- 缺失提醒
- 异常变化备注入口
- 历史月份始终可编辑，但记录操作日志

异常变化备注由用户手动填写，不强制。配置阈值用于提示：金额变化超过 20000 CNY 或比例变化超过 20% 时提示填写备注，但不阻止保存。

## 7. 导入导出和备份

MVP 支持四类导入模板：

- 机构 / 账户 / 项目模板
- 历史汇率模板
- 月度快照模板
- 债权债务事件模板

导入冲突策略：业务数据存在冲突时拒绝整批并提示用户修正模板，不自动覆盖。历史汇率以“币种 + 日期 + 来源”为唯一键，同键再次导入时更新汇率值。

完整备份恢复：恢复前要求重新输入密码，并自动备份当前数据。恢复成功后全量替换现有数据。

## 8. 安全和隐私

必须登录后使用。MVP 为私有单用户，不开放注册。

不保存完整银行卡号、完整证券账号、密码、密钥或银行登录凭据。账户字段只允许保存脱敏标识，例如尾号或自定义简称。

所有金额变更、导入、导出、恢复、登录失败、汇率同步失败都写入操作日志或系统日志。

## 9. MVP 非目标

MVP 不做：

- 移动 App
- 银行 API 同步
- 券商 API 同步
- 消费记账流水
- 真实投资收益率、IRR、TWR、成本法收益计算
- 股票、基金、债券行情同步
- 多用户注册
- 家庭成员协作
- 复杂利息计算
- 附件上传
- 移动端适配优先
